# Priyal Jaiswal — Animated Portfolio

Fully animated Data Analyst portfolio (GSAP + ScrollTrigger + Lenis).

## Open

```bash
open "/Users/priyaljaiswal/Desktop/Project/priyal-jaiswal-portfolio/index.html"
```

For best results (fonts/CDN), serve locally:

```bash
cd "/Users/priyaljaiswal/Desktop/Project/priyal-jaiswal-portfolio"
python3 -m http.server 5177
# open http://localhost:5177
```

## Add your photo (important)

Replace the placeholder with your headshot:

1. Export a clear portrait (recommended ~900×1200, face centered).
2. Save it as:

```
assets/portrait.jpg
```

Overwrite the existing file — keep the same name. Refresh the page.

On scroll, your photo will zoom, desaturate, and tilt as the hero exits — chips and copy fade with it.

## What’s animated

- Loading screen with progress
- Custom cursor + magnetic buttons
- Smooth scroll (Lenis)
- Split text hero / section titles
- Stat counters (94% / 50% / 2+)
- Portrait scroll morph
- Horizontal project scrub (OpsPilot → DMS → Metabase)
- Timeline fill + staggered bullets
- Skills marquee
- Contact glow scrub
- Top scroll progress bar
